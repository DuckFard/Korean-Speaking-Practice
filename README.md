## Overview of the Korean Speaking Test for level 1 students - 1급 말라기 시험
Over the course of 10 weeks, students of this course will take 2 test: 1 mid-term and 1 final term test. Each will be taken after every 5 weeks. Both of the test follow the same structure:
- **Part 1: Read Aloud:** Test-takers will be given a random snippet of a Korean text from a set of various snippets and are asked to read them aloud for the teacher to grade. The content is usually about the topics and themes they encounters while studying.
- **Part 2: Questions & Answer:** Given a list of topics, each with their own sets of questions, the examiner will cycle through all the topics and ask 1 random questions per each set.
- **Part 3: Interview/Presentation:** Test-takers will give a presentation, sometimes assisted with guiding questions from the teacher, about a random topic from a prepared list.
- **Part 4: Role Play:** This part is the same as Part 3. However, students will have to have a conversation with the teacher in order to achieve a goal they are randomly given, i.e ordering food, giving directions, answering the phones, etc.

## Getting Started

To get started with the project, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/DuckFard/Korean-Speaking-Practice.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd Korean-Speaking-Practice
   ```
3. **Install dependencies**:
   Ensure you have Node.js installed, then run:
   ```bash
   npm install
   ```
4. **Start the development server**:
   ```bash
   npm start
   ```
5. Open your browser and navigate to `http://localhost:3000` to access the application.
